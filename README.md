TripleTen Sprint 5 - De patria a patria — Web Project Homeland

Este proyecto se desarrolló como parte del Sprint 5 del curso de Desarrollo Web de TripleTen. El objetivo es crear una página web responsiva que presenta los lugares de origen de algunos colaboradores de TripleTen, aplicando conceptos de diseño responsivo, metodología BEM y buenas prácticas de HTML y CSS.


Objetivo del proyecto

- Practicar el desarrollo de diseños responsivos a partir de un diseño de Figma.

- Garantizar una buena experiencia de navegación en diferentes dispositivos y tamaños de pantalla (320 px, 768 px y 1280 px).

- Reforzar el uso de Flexbox, valores relativos (% y fr) y media queries.

- Aplicar una estructura de carpetas y clases siguiendo la metodología BEM.

- Publicar el resultado final en GitHub Pages.


Tecnologías utilizadas

- HTML5

- CSS3

- Flexbox

- Media queries (puntos de quiebre: 544 px y 1024 px)

- Figma para consultar el diseño

- Metodología BEM para organizar las clases CSS

- Tipografía Inter


Diseño responsivo

El sitio está diseñado para adaptarse a los siguientes tamaños de pantalla:

Móvil: de 320 px a 544 px.

Tableta: de 545 px a 1024 px.

Escritorio: más de 1024 px.
